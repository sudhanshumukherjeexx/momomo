# Starfall Meadow: Dream Drive

A magical 3D driving experience with interactive memories.

## How to Play
- W/S or Arrow Keys: Accelerate/Reverse
- A/D or Arrow Keys: Steer
- E: Interact with Memory Sprites
- H: Hide/Show UI

## Technologies
- Three.js
- WebGL
- JavaScript

## Setup
1. Clone the repository
2. Open `index.html` in a modern browser
3. Enjoy your journey!
